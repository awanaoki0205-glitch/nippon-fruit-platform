0.13.0
- 自動分類設定・品質チェック画面に、再分類の状態、処理段階、進捗率、完了・残り・AI待ち件数を追加

- 分類保存前に独立したカテゴリ整合性検証を追加しました。
- 単品の明確な商品名と矛盾する過去カテゴリを自動除外し、定期便・詰め合わせの複数大分類は維持します。

- 商品種別、品目、品種、重量、数量、サイズを分類属性としてDBへ保存します。
- AI出力を厳格な構造化データへ拡張し、低信頼度では既存カテゴリを変更しません。
- 品質チェックに「カテゴリ矛盾検出」と自動補正内容の一覧を追加しました。
- 手動確定商品はAIキュー実行時にも上書きしません。

【v0.9.48 主商品同定・SEO混入語の除去】
- 商品名に複数品種が並んでいても、詰め合わせ等でなければ先頭側へ最初に現れる具体品種を主商品として確定。
- 「巨峰 …発送予定 シャインマスカット ぶどう…」のような後半SEO語句を公開タイトルから切り離す。
- 主商品と矛盾する品種タグを自動解除し、カテゴリ一覧への混入を防止。
- 特徴文に別品種の説明が含まれる場合、その自動生成欄を非表示。
- 「食べ比べ・詰め合わせ・セット・定期便・選べる品種」は複数品種として維持。
- 「選べる容量」は単一品種として扱い、別品種SEO語句を許可しない。
- v0.9.47の分割全件再分類を新しい判定規則でも再実行。

【v0.9.47 タイトル主分類・全件分割再分類】

- 「定期便」「あとから選べるお礼品」のような横断カテゴリは維持。

- 新しい商品から先に修正し、残りはWordPressの予約処理で継続。
- v0.9.46までの商品説明・カテゴリ表示・スマホUI改善を維持。

更新方法と注意点
1. 通常のWordPressプラグイン更新としてZIPをアップロードし、既存プラグインを置き換えます。
2. 既存掲載は保存済みの商品名・capacityLabelからそのまま規格が補完されます。再登録は不要です。
3. v0.7.7以前はvariantごとの見出し・説明文を保存していません。それらにしか記載のない規格はYahoo!再同期後に表示されます。
4. 必要に応じてサイトやキャッシュプラグインのページキャッシュを削除してください。
5. 表記されていない重量・数量・サイズは推測しません。総重量の掛け算による推計もしません。
6. 商品説明の自由記述には抽出できない表現や曖昧な情報が残る場合があります。最終的な規格は各申込先で確認してください。
